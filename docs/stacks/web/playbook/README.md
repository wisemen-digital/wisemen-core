# WEB Playbook Structure

Add as many files and folders here as needed.

Recommended structure:

- `index.md` for the section landing page
- topic pages like `architecture.md` or `release-process.md`
- subfolders for larger areas like `components/`, `testing/`, or `delivery/`

When we start adding more playbook pages, we can either:

- keep the sidebar curated manually for a cleaner experience
- generate the sidebar from this folder automatically
