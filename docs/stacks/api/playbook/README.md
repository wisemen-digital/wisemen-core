# API Playbook Structure

Add as many files and folders here as needed.

Recommended structure:

- `index.md` for the section landing page
- topic pages like `conventions.md`, `integration-flow.md`, or `versioning.md`
- subfolders for larger areas like `payloads/`, `security/`, or `deployment/`

When this section grows, we can either:

- keep the sidebar curated manually for a cleaner experience
- generate the sidebar from this folder automatically
